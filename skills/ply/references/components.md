# コンポーネント

全コンポーネントのリファレンスです。カタログの各ページ（`/components/<id>`）と同じ内容で、見本の表示はカタログで確認できます。

## 作業面と移動

- [AppShell](https://github.com/tknf/ply/blob/main/docs/components/app-shell.md)：上部中央のコマンドメニューと、中央の作業面を持つアプリの骨格。
- [CommandMenu](https://github.com/tknf/ply/blob/main/docs/components/command-menu.md)：アプリ全体の移動・操作を検索する、上部中央の専用パネル。
- [SplitView](https://github.com/tknf/ply/blob/main/docs/components/split-view.md)：一覧と本文、作業と補足を並べる。
- [Wing](https://github.com/tknf/ply/blob/main/docs/components/wing.md)：中央の作業面の後ろから、左右に開閉できる補助パネルを差し込む。
- [Section](https://github.com/tknf/ply/blob/main/docs/components/section.md)：関連する内容を見出し・件数・操作とまとめる。
- [Surface](https://github.com/tknf/ply/blob/main/docs/components/surface.md)：中央の作業面。仕事の中身を一枚の白い面にまとめます。AppShellの作業面と同じ見た目で、AppShellを使わない画面で使います。
- [ContextBar](https://github.com/tknf/ply/blob/main/docs/components/context-bar.md)：現在の位置と関連する移動・操作を、作業面の上部にまとめます。
- [PageHeader](https://github.com/tknf/ply/blob/main/docs/components/page-header.md)：対象と作業を、大きな見出しで伝えます。
- [ProfileHeader](https://github.com/tknf/ply/blob/main/docs/components/profile-header.md)：大きなアバターと名前、この人への設定のバー
- [Breadcrumb](https://github.com/tknf/ply/blob/main/docs/components/breadcrumb.md)：階層をたどって上位へ戻る
- [BackLink](https://github.com/tknf/ply/blob/main/docs/components/back-link.md)：一つ上の場所へ戻るだけのピル
- [Navigation](https://github.com/tknf/ply/blob/main/docs/components/navigation.md)：同じ領域のページを切り替える
- [Tree](https://github.com/tknf/ply/blob/main/docs/components/tree.md)：中央の作業面で階層を開閉・選択する
- [TableOfContents](https://github.com/tknf/ply/blob/main/docs/components/table-of-contents.md)：長い資料の見出しへ移動し、現在地を示す
- [Tabs](https://github.com/tknf/ply/blob/main/docs/components/tabs.md)：同じ場所で関連するパネルを切り替えます。
- [Pagination](https://github.com/tknf/ply/blob/main/docs/components/pagination.md)：分割された一覧を移動します。
- [Steps](https://github.com/tknf/ply/blob/main/docs/components/steps.md)：手順と現在の段階を示す
- [Divider](https://github.com/tknf/ply/blob/main/docs/components/divider.md)：意味のある区切りと見出しを置く
