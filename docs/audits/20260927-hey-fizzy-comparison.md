# HEY・FizzyとPlyの違い（2026年9月27日）

「重ねた紙と文具」で全コンポーネントを作り直した状態（`8af36d9`）を、HEY・Fizzyと比べる。ユーザーの評価は「個人的には結構好き。でもHEYと違って悪目立ちするデザインになった」。この文書は、何が悪目立ちを生んでいるかを、実物の値で言える形にする。どう直すかは決めない。決めるのは次の作業（ディテールの作り直し）で、ここではその判断材料だけを並べる。

## 要約

1. **比喩の置き場所が違う。** HEY・Fizzyは比喩を名前と振る舞いに置き、見た目は平らにする。Plyは比喩を形に描いた。語彙表は34行あり、ほぼ全てが「何の文具に見せるか」を決めている。
2. **中身より器が強い。** Plyのボードでは、カードの題名（14px・400）より、上に載る荷札（13px・600）と列の札（13px・600、墨の地）の方が太い。人は10pxの頭文字になる。HEY・Fizzyでは題名と人が画面でいちばん強い。
3. **階層を文字ではなく素材で作っている。** Plyのボード画面は、机（灰色の地）・作業面の紙・沈んだトレイ・カードの紙・シールの札と、素材が4層重なる。Fizzyのボードは白い地にカードの1層、HEYのDraftsは白い地に行が平らに並ぶ。
4. **飾りが常設で、しかも均等に散っている。** Plyのボード画面は、見えている135要素のうち21に影、15にグラデーション、14に飾りの疑似要素がある。Fizzyのボードで光るのは、特別扱いのカード1枚と、たたんだ列1本だけ。
5. **色の彩度と面積が逆。** HEY・Fizzyは彩度の高い色（彩度0.8〜1.0）を少ない場所に大きく置く。Plyは彩度の低い色（多くは0.2〜0.3）を、札・切手・列の地など小さい場所に数多く置く。
6. **楽しさが出る時が違う。** Fizzyのゴム印は完了した時だけ押される。HEYの今日の楕円は画面に一つ。Plyでは切手のミシン目・封蝋・荷札の穴が、全ての行に最初から付いている。
7. **Plyが意図して違えている所もある。** 情報の密度（ClickUp並み）、上部中央のCommandMenu、日本語の組版は、HEY・Fizzyに合わせる対象ではない。違いのうち、どれが悪目立ちの原因で、どれがPlyの個性かを分けて扱う。

## 1. 比喩の置き場所

| 製品  | 比喩の置き場所 | 例                                                                                                                                                                                                                                      |
| ----- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HEY   | 名前と振る舞い | Imbox、The Feed、Paper Trail、Set Aside、Reply Later、Bubble Up、The Screener[DOM]。画面の見た目は白い地に文字の一覧で、名前が紙や郵便を言っても、行に紙は描かない[画像]                                                                |
| Fizzy | 名前と振る舞い | 列の名前がNOT NOW・MAYBE?・ON HOLD・DONE[DOM]。放っておくと「Not Now」へ移る（Moves to "Not Now" in 365 days）[画像]。文具を描くのは完了のゴム印と期限の円形スタンプの二つだけ[DOM]                                                     |
| Ply   | 見た目         | 語彙表34行のうち、ピル・太字のラベルなど数行を除き、部品ごとに別の文具を描く。切手（MessageListの差出人）、封蝋（未読）、荷札（Tag）、シール（Badge）、付箋（Notice）、切符（ActionList）、メモパッド（TaskList）、定規（Progress）など |

- Plyの語彙の名前（ミシン目、ゴム印、付箋）は、利用者の画面には出ない。開発者向けの設計の言葉で、見る人が受け取るのは形だけになる。
- HEY・Fizzyの名前は、利用者が毎日読む画面の言葉。比喩は読むたびに効き、見た目は邪魔をしない。
- [仮説]「HEYは比喩を名前と振る舞いに込め、Plyは見た目で描いた」は、実物と合う。

## 2. 主役：中身か器か

同じ種類の画面で、いちばん強く見える要素を比べる。

### 一覧の行（HEYのDrafts、PlyのMessageList）

| 要素               | HEY                                    | Ply                                                                                                       |
| ------------------ | -------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 題名               | 約19.8px・通常の太さ[DOM][画像]        | 14px・600[Ply]                                                                                            |
| 補足（差出人など） | 15.4px、文字色を透明度66%に下げる[DOM] | 差出人13px・600、本文の抜粋13px・400[Ply]                                                                 |
| 人                 | 直径44pxの紫の円、太字の頭文字[画像]   | 38pxの切手（ミシン目の縁）の中に、10px・600の頭文字[Ply]                                                  |
| 未読               | （今回の記録にない）                   | 未読の行ごとに20pxの封蝋。-8度に傾け、放射状のグラデーション、2本の内側の輪、内側の影、落ちる影の4層[Ply] |

HEYでは人の円と題名が行の中で最も大きい。Plyでは人が10pxの字になり、切手の縁と封蝋の艶が、題名と同じくらい目を引く。

### ボードのカード（Fizzy、PlyのBoard）

| 要素     | Fizzy                                                             | Ply                                                     |
| -------- | ----------------------------------------------------------------- | ------------------------------------------------------- |
| 題名     | 約20px・太字（大文字の高さ14px）[画像]                            | 14px・400[Ply]                                          |
| 分類     | カード上端のフォルダの見出し（番号｜ボード名）、小さな大文字[DOM] | 荷札のTag、13px・600、紐の穴と補強のリング、色の地[Ply] |
| 列の名前 | 約14pxの大文字（大文字の高さ10px）、地も線もない[画像]            | 13px・600、墨で塗った札が列の上端をまたぐ[Ply]          |
| メタ情報 | 約11pxの大文字、縦線で区切る[画像][DOM]                           | 担当者の円24px（頭文字10px）、状態の選択[Ply]           |
| 人       | 直径32pxの赤い円[画像]                                            | 直径24pxの淡い円、頭文字10px[Ply]                       |

- Plyのボードでは、**題名が荷札より細い**。カードの中で最も太い字が分類の札で、次が列の札。仕事の中身（題名）が三番目になっている。
- Fizzyは題名を太く大きくし、分類と日付を小さな大文字に落とす。器の文字は小さく、中身の文字は大きい。
- [仮説]「HEY・Fizzyでは中身が主役で、器は黙っている。Plyは器が主役になった」は、ボードとメール一覧の実測と合う。

## 3. 階層の作り方：文字の段か、素材の層か

### 文字の段

| 役割         | HEY                    | Fizzy                | Ply                                   |
| ------------ | ---------------------- | -------------------- | ------------------------------------- |
| 画面の見出し | 44px・700[DOM]         | 約28px・太字[画像]   | 28px・700[Ply]                        |
| 項目の題名   | 19.8px[DOM]            | 約20px・太字[画像]   | 14px（メールは600、ボードは400）[Ply] |
| 本文         | 17.6px[DOM]            | —                    | 15〜16px（`--ply-body`）              |
| 補足・日付   | 15.4px、透明度66%[DOM] | 約11px、大文字[画像] | 13px、`--ply-muted`の色[Ply]          |
| 最小の字     | —                      | 約11px               | 10px（頭文字）[Ply]                   |

- 見出しと題名の比は、HEYが44÷19.8＝2.2、Plyが28÷14＝2.0で近い。**差が出るのは題名と補足の間**。HEYは19.8対15.4、Fizzyは約20対約11で、題名がはっきり一段上にある。Plyは14対13で、題名と補足がほぼ同じ大きさになり、太さも補足（差出人13px・600、荷札13px・600）の方が強い場合がある。
- Plyの基準（一覧14px、補足13px）はClickUpの密度から採った値で、意図した違い（[採用値](../references/measurements-20260915.md)）。密度を保つなら、大きさではなく**太さと色の段**で題名を補足の上に置く必要があるが、今は補足と札が600を使い、題名の方が弱い所がある。
- Fizzyは英語の小さな大文字でメタ情報を一段下げる。日本語には大文字がないため、Plyにはこの段の代わりが決まっていない。

### 素材の層

| 画面                    | 重なる素材                                                                | 層の数 |
| ----------------------- | ------------------------------------------------------------------------- | ------ |
| HEYのDrafts[画像]       | 白い地、ごく淡い温かい影の大きな白い面、平らな行                          | 1      |
| Fizzyのボード[画像]     | 白い地、影を持つカード                                                    | 1      |
| Fizzyのカード詳細[画像] | 淡い青の面（`#bad0f7`）、その上の白いカード                               | 2      |
| Plyのボード[Ply]        | 灰色の机（`#f3f6f8`）、作業面の紙、沈んだトレイ、カードの紙、シールの荷札 | 4      |
| Plyのメール一覧[Ply]    | 灰色の机、作業面の紙、一覧の紙（影と角丸）、切手、封蝋                    | 4      |

- HEY・Fizzyは階層を文字と余白で作り、素材はほぼ一枚。層を足すのは、Fizzyのカード詳細のように「この一枚を見て」という場面だけ。
- Plyは階層を素材の重なりで作っている。層ごとに影と地の色が変わるため、影と面の種類が画面に増える（次の節）。
- [仮説]「HEY・Fizzyは階層を文字の大きさ・太さと余白で作る」は、実物と合う。

### HEY・Fizzyで飾りが出る場所

- **Fizzyのボード**[画像]：黄色く光るカード1枚（`#fef7cb`、特別扱いのgolden）、たたんだ列ON HOLDのピルのグラデーション1本、画面下の積み重ねたカード。普通のカード2枚は白い面に影だけ。スタイルシート全体でグラデーションは12か所[DOM]。
- **HEY**[DOM]：グラデーションは63か所あるが、使う所は通知の島・ページの操作帯・ページ送り・ポップアップメニュー・振り分けの状態・見出しの線に限る。一覧の行と本文の面は平ら。模様は夜の時間帯・既読の境目・仮の予定・Clipsと、場所を決めて使う。
- スタイルシートの数そのものは比べられない（PlyのCSSは`gradient(`が77か所、HEYは63か所）。違いは数ではなく、**一覧の行や小さな部品にまで付くかどうか**にある。

### Plyで飾りが行ごとに繰り返される所

- MessageList：全ての行に切手（ミシン目の縁、-3度・2度と傾ける）、未読の全ての行に封蝋（-8度）。3行の一覧で、傾いた要素が6（切手3、封蝋3）、影を持つ要素が7。
- Board：全てのカードに紙の影、全ての荷札に紐の穴とリング、全ての列に沈んだ影と札。
- Tag：全ての札に落とした角と穴。Badge：全てのシールに艶と影。
- ActionList：全ての入口に半券のミシン目と切り欠き。

一つずつは小さいが、同じ強さの飾りが行の数だけ並ぶ。HEY・Fizzyで飾りが一画面に一つか二つなのと比べ、Plyは十数か所になる。

- [仮説]「楽しさは節目に一つだけ出るので効く。Plyは同じ強さの飾りが画面中に散った」は、数の上でも合う。

## 8. 色

採色は画像[画像]とPlyの撮影[Ply]の画素から取った。彩度はHSLの値。

| 役割         | HEY                                                            | Fizzy                                             | Ply                                                |
| ------------ | -------------------------------------------------------------- | ------------------------------------------------- | -------------------------------------------------- |
| 主操作       | `#0073f8`（彩度1.00）                                          | `#2b75f0`（0.87）                                 | `#2d7aca`（0.64）。135度のグラデーション           |
| 人           | 紫の円`#968efb`（0.93）                                        | 赤い円`#bc1d22`（0.73）                           | 淡い円`#fff0ed`、切手の地`#edf5ef`（0.29）         |
| 機能の色     | 戻るのミント`#a2fff0`（1.00）、今日のオレンジ`#f98f17`（0.95） | ON HOLDの橙`#f6bd7a`（0.87）、goldenの黄`#fef7cb` | 荷札の地`#eedeaf`（0.65）、列の地`#e8ecef`（0.18） |

## 9. 文字の作法

| 作法             | HEY・Fizzy                                                       | Ply                                                            |
| ---------------- | ---------------------------------------------------------------- | -------------------------------------------------------------- |
| 見出しの左右の線 | 画面の見出しの左右へ線を伸ばす（HEYは青から紫）[DOM][画像]       | 中央のPageHeaderとまとまりの見出しで線を伸ばす（右へ一本が主） |
| 小さな大文字     | 区切りの見出し・メタ情報・列の名前[DOM]                          | 日本語に大文字がないため代わりがない                           |
| 近道のキー       | 主操作の中に添える（Add a card [C]、Edit [E]、SEARCH [K]）[画像] | CommandMenuの起動と入口にはKeycapを添える。Buttonには添えない  |
| 補足の下げ方     | HEYは色ではなく透明度66%[DOM]                                    | `--ply-muted`の色                                              |
| 日付の強弱       | 曜日を小さく、数字を太く（SUN 27）[画像]                         | Calendarで同じ作り                                             |

文字の作法の差は小さい。悪目立ちの原因というより、HEY・Fizzyが飾りの代わりに使っている手段で、Plyが飾りを減らした時の受け皿になる。

## 10. 語彙の数と、同じ構造の繰り返し

| 項目               | HEY                                                              | Fizzy                                                                               | Ply                                                                          |
| ------------------ | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 見た目の語彙       | ピル、見出しの線、枠に載せた見出し、太枠、波線、場所を決めた模様 | カード、ピル、円、ゴム印、円形スタンプ、たたんだ列                                  | 語彙表34行                                                                   |
| 同じ構造の繰り返し | どの画面も同じピルと見出しの線                                   | カードは「フォルダの見出し・太字の題名・小さな大文字のメタ情報」がどこでも同じ[DOM] | 一覧の項目の順（題名・補足・メタ）は規則にあるが、見た目は部品ごとに別の文具 |

- Plyの規則は「同じ意味には同じディテール」だが、実際には「**部品ごとに一つの文具**」になっている。MessageList・TaskList・ActionList・DataListは、どれも一覧の行なのに、切手・メモパッド・切符・短冊と別の物に見える。
- Fizzyは、ホーム・ボード・詳細・画面下の積み重ねで、同じカードの構造を繰り返す。見る人は一度覚えれば、どこでも読める。
- [仮説]「語彙を数個に絞る」は、この差から出てくる案の一つ。

## 11. Plyが同じ所、意図して違える所

悪目立ちの原因と混ぜないため、違いではない所と、意図した違いを分けておく。

### すでに同じ考え方

- 押す物はピル。主・控えめ・危険を形ではなく塗り・枠・色で分ける。
- 画面の見出しから線を伸ばす。新着の境目の波線。「今」を示す太枠。
- 使えない枠の斜線、目印の蛍光ペン。どちらもHEYの「場所を決めた模様」と同じ使い方。
- グラデーションを「ここを見て」の面に限る規則（ただし4節の通り、押す物の陰影として小さな部品にも付いている）。

### 意図して違える所

- 情報の密度。一覧14px・補足13px・Button 32pxはClickUpの密度から採った値で、HEYの大きな文字は写さない。
- 上部中央のCommandMenuと中央の作業面（サイドバーを持たない）。
- 日本語の組版（`word-break: auto-phrase`、行メトリクスの補正）。

### Plyにしかなく、評価の高いもの

- 出来事の瞬間の動き：確定でペンが書くチェック、ゴム印を押す、運ぶ紙が傾く、荷札が揺れる。
- これらはFizzyのゴム印と同じ種類の楽しさで、残す理由がある。

## 13. 決めたこと（9月27日）

この文書を読んだユーザーが、次のように決めた。

- デザインシステムが比喩の語彙を持つ意味はない。ゴム印・波線・ミシン目のような表情は、アプリごとに定義すればよい。
- 今の版の**立体感と手触りは残す**。紙の影、押す物の陰影、押した時の沈み、出来事の瞬間の動き。
- **文具の形の装飾は全て消す**。しおり、飾りの破線、切符、切手、封蝋、荷札、シール、付箋ののり、テープ、余白線、メモパッド、方眼、定規の目盛り、取扱注意の縞、添削用紙、重ねた紙の図、ゴム印、波線、墨のつまみ。ファイルのドロップ先や空の列の「ここに置ける」破線は、操作の目印として残す。
- **大きさと余白をHEY・Fizzyのようにゆったりさせる**。値は本家を見て決める。9月27日にもう一度HEY・Fizzyを開いて測り（[実測](../references/hey-fizzy-20260927/README.md)）、一度は日本語に合わせて一段下げた中間の案（補足14px・操作16px・本文と題名18px）を入れた。画面で見たユーザーの判断で、見出し（小見出し22px・画面見出し36px）はHEYに寄せたまま、普通の文字はFizzyくらい（補足13px・操作14px・本文と題名16px、Button 36px）に戻した。
- **HEYにさらに寄せる**。やわらかな立体感は残し、縁取りを外す。地を白にし、作業面は角丸30pxと縁取りのない淡い影で浮かせる。紙の影から1pxの輪郭と縁の光の線を外し、人の円の枠線、パンくずの帯の区切り線、完了のCardの緑の輪郭もやめた。

4つの案との関係では、「常設の見た目と出来事の見た目を分ける」と「語彙を絞る」を、語彙そのものを持たない形で採った。「大きい面だけが紙を持つ」も、紙の影を残す場所として一致する。

## 付録：計測の方法

- [Ply]の数値は、scratchpadに置いたPlaywrightのスクリプトで取った（リポジトリには置かない）。見えている要素（`display: none`・大きさ0を除く）について、`getComputedStyle`の`box-shadow`・`background-image`・`mask-image`・`clip-path`・`transform`／`rotate`と、`::before`・`::after`のうち内容を持ち、影・背景・mask・枠のどれかを持つものを数えた。「別々の影」は`box-shadow`の値の種類の数。長い値は先頭60文字と長さで区別したため、実際の種類はこれより多いことがある（少なくともこの数）。
- [画像]の数値は、PILで指定した範囲の暗い画素（明るさ150未満）または指定色に近い画素の外接矩形を取った。対象はHEYの`hey-09-drafts.png`・`hey-02-calendar-week.png`・`hey-06-compose.png`、Fizzyの`fizzy-03-board.png`・`fizzy-07-card-detail.png`。
- Plyのスタイルシートの数（`src/css`）：`gradient(` 77、`box-shadow` 170、`mask` 26、`clip-path` 23、`::before`／`::after` 111、`@keyframes` 11、影のトークン17。
