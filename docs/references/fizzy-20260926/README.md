# Fizzyの実測

2026年9月26日、ユーザーから自由に使ってよいと許可されたFizzyのアカウントを、ログイン済みのChromeで確認した。ホーム（Latest Activity）、ボード、カードの詳細を開いた。実在の名前が表示されるため、画像は保存していない。寸法はDOMとスタイルシートの値。

## 規則の作り方

- 同じ形を繰り返す。カードはどこでも「フォルダの見出し（番号｜ボード名）・太字の題名・小さな大文字のメタ情報を縦線で区切った行」の同じ構造で、ホーム・ボード・詳細・画面下の積み重ねで変わらない。
- トークンは少ない。余白は`--inline-space: 1ch`と`--block-space: 1rem`の半分・倍だけ。文字は`x-small`〜`xx-large`の8段。色はOKLCHのインクの段と役割色。
- 角丸は文字に連動する小さな値（0.2em、0.25ch）、ボタンはピル（99rem）、アバターは円。面ごとに違う角丸を作らない。

## グラデーションと影

- スタイルシート全体でグラデーションは12か所だけ。使うのは、特別扱いのカード（golden：黄色の光）、つまみ、線の端のフェード、システムが書いた記録の斜線、たたんだ列の端。普通のカードや一覧は平らな面。
- 影を持つのは、手に取れる物（カード）と、浮かぶ物（ポップアップ、トレイ、設定のパネル）だけ。カードの影は`0 0 0 1px`の輪郭と、0.2em・0.4em・0.8emの同じ濃さ（5%）の3段。
- キーの表示（kbd）は`currentcolor 0 0.1em 0`の硬い影で、押せるキーに見せる。

## 文具の語彙

- 完了は傾いたゴム印（DONE・日付・名前）。期限は円形のスタンプ（CLOSES IN 73 DAYS）。
- たたんだ列は、件数と縦書きの列名を持つ縦長のピル（NOT NOW、DONE）。
- 画面見出しは中央で、左右に線を伸ばす。区切りの見出し（WATCHING FOR NEW CARDS）も線の間に置く。
- 主操作はピルで、中に近道のキー（C、B、F）を添える。画面下の帯も「SEARCH [K]」「NOTIFICATIONS [N]」のように小さな大文字とキー。
- 状態の選択肢（NOT NOW、MAYBE?、ON HOLD、DONE）は小さな大文字の縦の一覧で、選んだものだけ濃い面で塗る。
- 列の色でカード全体を淡く染める（ON HOLDは橙）。

## Plyへの持ち込み方

見た目を写さず、規則の作り方を持ち込む。同じ意味には同じ構造を繰り返し、グラデーションと影は「ここを見て」「手に取れる」「浮いている」所だけに使う。
