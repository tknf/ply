## 読み取れる関係

- 本文と一覧の題名は19〜20px。補足は15px前後、大文字の小さなメタ情報は12px前後。題名と補足の比は、HEYが1.29、Fizzyのボードが1.6。
- 最小の文字（10〜12px）は、大文字のラベルやキーの表示だけに使う。
- 操作の高さは36〜37px、文字は14〜18px。大きな戻る操作だけ約50px。
- 大きな面は、左右に50px前後の余白を取る。
- 余白は文字の大きさに連動する一つの基準から、半分・倍で作る。

## HEYの縦並びの一覧（action-group）

設定の入口（Accounts & Settings）とHEYメニューで、同じ`action-group`を使う。値は計算値とスタイルシートの規則から拾った。

| 要素                | 値                                                                                |
| ------------------- | --------------------------------------------------------------------------------- |
| 行                  | 高さ53.8px、19.8px・500。先頭に3emのアイコンの列（`::before`、アイコンは1.125em） |
| 指を載せた時        | 行に黒の6%の面                                                                    |
| 今いる行            | 面は塗らない。終わりの側に選択の印（チェック、1em）を置き、右の余白を2emに広げる  |
| まとまり（surface） | 行の板に黒の3%の面。最初の行の上と最後の行の下の角だけ0.8remの角丸                |
| 行の間              | 1pxの線（黒の5%）。アイコンの列を避け、名前の書き始め（3em）から終わりまで        |
| まとまりの間        | 1em                                                                               |

HEYメニューの大きな入口（Imbox、The Feedなど）だけは、今いるものを濃い面（黒の12%）で塗る。
