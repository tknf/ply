# HEYのImboxの実測

2026年9月26日、ユーザーから閲覧を許可されたHEYのImboxを、ログイン済みのChromeで確認した。実在のメールと差出人が表示されるため、画像は保存していない。寸法と色はDOMの計算値。操作・送信はしていない。

## 観察

- ページ見出しは中央に大きく置く（44px・太さ700）。見出しの下に色の細い線を引く。
- 本文の基準が大きい（本文17.6px、行の本文19.8px）。日付は15.4pxで、文字色を透明度66%に下げる。
- 主操作は鮮やかな紫の丸い形のボタン。アバターも同じ紫の円に頭文字。
- ラベルは塗らずに1pxの色の枠線と同じ色の文字だけ（15.4px、丸い形、上下0.77px・左右7.7px）。
- 既読の区画は温かい地色で塗り分け、小さな大文字の見出し（PREVIOUSLY SEEN）を置く。
- 空の状態に絵文字の「✨」、区画の境目に紙吹雪のような模様を使い、遊びを持たせる。

## Plyへの読み替え

Plyは汎用の土台としてこれらを既定値にはしない。代わりに、構造を変えずにトークンの差し替えで同じ方向へ振れるようにする。主操作の色と形（`--ply-brand`、角丸）、見出しの大きさと揃え、区画の地色（Surfaceのtone）、ラベルの塗りの有無、本文の大きさを、コンポーネントの固定値ではなくトークンから決める。

## メールとカレンダーを一通り操作して集めたディテールの語彙

最初の確認はImboxだけだった。Imbox、The Feed、Paper Trail、Focus & Reply、Set Aside、Bubble Up、The Screener、スレッド、作成画面、Contacts、Clips、設定、カレンダーの日・週・年、予定の作成、Habits（新規）、Tracked time、Journalを開いて追加した。メールは送信せず、予定・習慣も保存していない。

### 形

- ボタン・リンク・ラベル・戻る操作は、ほぼ全てが丸型（ピル）。四角いボタンはない。違いは形ではなく、塗り・枠線・色で出す。
  - 主操作：塗り（青・紫・黒に近い色）。
  - 控えめな操作：塗りなし、枠線は文字色の15%、文字は66%。
  - 用途を示す操作：塗りなし、枠線と文字だけアクセント色（Exportは青、Newは紫、draftsは青）。
  - 戻る：ミントの塗りの丸型で左上に固定（「< Imbox」「< Week」）。画面内の戻るは中央上の枠線だけの丸型（「← Back to Habits」）。
- 丸型を二つに割る：ワークフローは左が塗り（Test Progress）、右が枠線だけの選択部分（審議 ⇕）。
- 大きな面は大きく丸い（メールのカード約30px）。フォームの枠と入力欄は小さく丸い（約7px）。
- 吹き出し：メモは角丸を一か所だけ0にする（33px 33px 0）。

### 線と枠

- 見出しの左右に線を伸ばす（The Feed、Paper Trailなど全ての画面見出し）。線は青から紫へ変わる。
- 区切りの見出しは大文字の小さな太字で、右へ線が伸び、線の端にリンク（「Clear all…」）。
- 新着の区切りは波線（SVGを背景にしたwavy）。
- 設問は枠で囲み、見出しを枠線の上に載せる（fieldsetとlegend）。枠は文字色の15%。
- 「今」や「編集中」は黒い太線（2px）で囲む：今週の枠、予定作成のパネル。
- 枠線をまたいで部品を載せる：Set Asideの「Mark all as Done」、スレッドの開閉ボタン、予定作成の「All day」、今日の楕円は枠からはみ出す。
- 入力欄は囲まずに下線や区切り線で並べ、フォーカスした欄だけ角丸の枠と輪を出す。フォーカスの輪は`box-shadow: 0 0 0 2px`の淡い青。
- 予定作成の日時は、値そのものに下線を引いて「書き換えられる文字」に見せる。

### 塗りと模様

- 空の状態は、画面ごとに色を変えた有機的な形（ブロブ）と白いカード、要点だけ太字。Bubble UpやTracked timeは手描きの線が重なる。
- 決まった場所だけ模様を使う：夜の時間帯は星空とギザギザの縁、既読の区画の境目は紙吹雪、仮の予定は斜線、Clipsは蛍光ペン。
- メニュー・日付の移動・HEYメニューは、青から紫のグラデーションの面。
- 影は暗くしない。温かい灰色で大きくぼかす（`rgba(226,221,215,.5) 0 0 33px`）。

### 文字と数字

- 画面見出しは中央に大きく太く、日付の見出しは「September 26」を太字、「Sat」を細字にして強弱を付ける。
- 曜日は小さな大文字、日付の数字は太字（「SUN 27」）。月名は縦書きで週の左端や月の変わり目に差し込む。
- 近道のキーを操作の右上に小さく添える（R・L・A・Z・M、H・1〜6）。
- 補足の文字は色を下げずに透明度で下げる（66%）。

### 色

- 機能ごとに色を持つ：主操作の青、新規の紫、戻るのミント、今日と現在時刻のオレンジ、ワークフローのコーラル。
- カレンダーの切り替えスイッチは、地の色がそのカレンダーの色。
- ラベルの色は8色の見本から選ぶ（青・赤・金・緑・青緑・紫・ピンク・トープ）。
