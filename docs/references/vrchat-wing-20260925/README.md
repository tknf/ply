# VRChatのWingの参照画像

2026年9月25日、Wing部品の再設計のために公開資料から取得した3枚。ローカル研究用で、カタログの公開資産には含めない。VRChatの実機やログイン済みの画面は確認していない。取得元とSHA-256は[manifest.json](manifest.json)に記録した。

## 観察

- Wingは作業面の外に並ぶ列ではなく、作業面の後ろへ差し込まれた一回り小さい面。作業面の縁が手前に重なる。
- 閉じた時は外側に細い持ち手だけが見え、上端にWingの印がある。開くと持ち手から外側へパネルが出る。作業面は動かない。
- 開いたパネルは見出し（メニュー・題名）、操作、一覧を持ち、高さは作業面より少し低い。内容はパネル内でスクロールする。
- 左右とも同じ構造で、持ち手は常に外側。
