# 実画面の測定とPlyへの採用値

2026年9月15日、ログイン済みの実画面でDOMの矩形とcomputed styleを測定した。Chrome、1920px幅、devicePixelRatio 1。スクリーンショットは撮り直さず、会話記録に残っていた元の画像を復元した。

| 対象                      | 実測                                          | 構成上の意味                                                       |
| ------------------------- | --------------------------------------------- | ------------------------------------------------------------------ |
| ClickUp Boardの題名       | 14px／20px、500、字間normal                   | 日常の対象名を大見出しにしない                                     |
| ClickUp Boardのカード     | 幅246px、高さ100px、角10px                    | 少ない情報をコンパクトに置く。全カードの高さを固定する根拠ではない |
| ClickUpの表示切り替え     | 13px、400、項目の箱高24px                     | 表示切り替えの主張は本文より弱い                                   |
| Basecamp Jump Menu        | 幅480px、上20px、角16px、白地、背景の暗転なし | 全体移動は上部中央から開く軽い面                                   |
| Basecampの主要な入口      | 4列、各104.5×74px、gap12px                    | 少数の入口だけを面にし、残りを行で読む                             |
| Basecampの検索            | 454×42px、16px／24px、400                     | 入口の下、一覧の直前に置く                                         |
| Basecampの一覧            | 高さ32px、16px／24px、上下4px、行間4px        | 最近の場所などは一行で走査できる                                   |

## 今回Plyへ採用する関係

- 一覧・ラベルは14px／20px。補足は13px／20px。読む本文は16px／26px以上。字間はnormal。見出し、既読・未読など意味のある差だけを太くする。
- Buttonと一行Inputは32px、largeは40px。既存の字形補正を維持する。Basecampの42pxを採るためだけに別の入力寸法を増やさない。
- 主要な関連要素の間は8px、補足は4px、情報のまとまりは16px、独立したセクションは24px。外側の親がgapを所有する。
- CommandMenuは480px、主要な入口4列、その下に検索と一列の場所・操作。native popoverで暗転させず、Escで起点へ戻る。
- ポインターで密度を保つ箇所と、タッチで44px以上必要な箇所を区別する。文字拡大や折り返しを固定高で切らない。
- ClickUpのサイドバーは採用しない。中央の作業面と上部中央の移動というユーザー指定を守る。

数値は参照先の全画面・全状態の規則を断定するものではない。Plyの採用値と参照先の実測値を混同しない。
