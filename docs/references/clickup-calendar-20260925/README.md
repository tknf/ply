## 追加で確認した挙動（2026年9月26日）

最初の確認では見た目の寸法だけを測り、挙動と設定を見ていなかった。表示の切り替え・設定・スクロールを操作して追記する。表示は確認後に元の週表示・週末表示ありへ戻した。

- 表示の切り替え：日・稼働日（月〜金）・週・月、日数（2〜9日と任意）、週末の表示、並べて表示。一覧（アジェンダ）表示はない。
- 週・日の時間割は0〜24時を常に描画し、画面の高さのスクロール領域に入れる。曜日の見出しと終日の行はスクロールしても上に固定される。開くと現在時刻が見える位置へスクロールする。時刻は「01:00」の2桁表記。
- 月は月ごとに区切らず、週の行が縦に続くスクロール。左端に週番号の列、月の初日に「Oct」のラベル。当月外の日は面を灰色にする。
- 週表示では見出しの月の横に「週39」を出す。週番号は週の木曜日で決まるISO週番号と一致した（日曜始まりの9月20日〜26日が39）。
- カレンダーの設定：グリッドの大きさ（デフォルト・大・XL）、予定の表示（控えめ・ベタ塗り）、新しい予定の既定の長さ、週の開始曜日（このアカウントは日曜日）、タイムゾーン、週末の表示、週番号の表示、常に週の初めを表示、非稼働時間を暗くする。
