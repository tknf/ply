# DatePickerの設計メモ

2026-09-12のユーザー提供画像2枚をUIの基準にする。単日の画像ではカレンダー上部に日付欄が1つ、期間の画像では2つある。カレンダー下部の「終了日」スイッチがその表示と連動する。ユーザーから、Shift＋クリックは終了日を自動追加してスイッチも有効にする操作だと説明を受けた。

Notionの公式資料でも、End dateを有効にして期間を指定する操作が説明されている。Shift＋クリックによる終了日の追加は2023-08-08の公式リリースノートに記載されている。[データベースのプロパティ](https://www.notion.com/ja/help/database-properties)、[Notion 2.32](https://www.notion.com/releases/2023-08-08)

今回のNotion参照は提供画像と公開資料によるもの。Notionアプリやスマホ実機を操作しての確認はしていない。Computer useはユーザーの指示により使用しない。

## 実装に反映すること

- 日付の表示欄は1つ。カレンダー上部で日付、または開始日・終了日を直接編集する。
- flexibleの「終了日」を有効にすると上部に2つ目の欄を表示する。Shift＋クリックも同じ状態にする。
- タッチでは終了日スイッチと日付のタップで選択する。長押しのような隠れた操作を必須にしない。
- カレンダーの選択・スイッチはその場で反映し、閉じても保持する。上部の日付欄へ不正な日付を入力している間は前回の確定値を保持する。
- 期間の端点をカレンダーで編集し逆転する場合、その期間内で同日に揃える。独立した別のDatePickerの値は変更しない。
- 日付の必須性、単日・期間の種別、送信フィールド名はサーバーがviewを組む時に指定する。
- 独立した日付間の大小関係はminFrom/maxFromで明示し、項目名から推測しない。

日付の形式変更・時刻・リマインドは今回のDatePickerの対象外。色や入力欄の基本寸法はPlyの共通スタイルを使い、タッチでは日付セルと終了日スイッチの操作領域を44px相当に広げる。

## 選択状態と表示順序

- 選択日と期間の端点は青い塗りと白い文字、期間の内側は淡い青の帯にする。ホバー・押下で選択色を薄くしない。
- 今日には文字色の小さな点を添える。赤色を使わず、選択状態や入力エラーと区別する。
- 上部入力欄は編集中の端点を青い枠で示す。クリアはカレンダー内側と左右を揃えた全幅ボタンにし、文字を中央に置く。月送りと今日のボタンも含め下線を付けない。
- パネルは非表示のまま実寸を測り、入力欄と表示領域に合わせて座標を設定してから表示・フォーカスする。再度開く場合もこの順序を守る。
- ソフトキーボードや拡大による表示領域の変化にも、寸法制限と再配置を追従させる。
